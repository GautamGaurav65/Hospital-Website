# 🏥 Hospital Website

A modern and responsive Hospital Website developed using HTML, CSS, and JavaScript. 
This website provides a simple and user-friendly interface for patients to explore hospital services and information.

## 🚀 Features

- 🏥 Hospital Home Page
- 👨‍⚕️ Doctors Information
- 🩺 Medical Services
- 📅 Appointment Section
- 📞 Contact Information
- 📍 Hospital Location
- 📱 Responsive Design
- 🎨 Modern and Clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
